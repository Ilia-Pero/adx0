# Addresses shared by the program and the extension

`essential.json` lists sites that a list of ads cannot block: finding one of them there is a mistake of the list. Their ad subdomains are blocked as usual.

`own.json` lists ad servers and counters of Yandex and Mail.ru. Public lists block them by parts of an address, which the hosts file cannot do. Checked on 2026-11-23.
