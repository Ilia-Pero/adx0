# Addresses shared by the program and the extension

`essential.json` lists sites that a list of ads cannot block: one of them in a list is a mistake of the list. Ad subdomains of these sites are blocked as usual.

`own.json` lists ad servers and counters of Yandex and Mail.ru that lists block only by parts of the address, which the hosts file cannot do. Checked on 2026-11-23.
